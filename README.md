# Estate Agent SPA

A single-page estate agent application built with React.  
Users can search, filter, view, and favourite properties using a clean and responsive interface.

---

## ✨ Features

- Search properties by type, price range, bedrooms, date added, and postcode area
- View property details on a dedicated page
- Image gallery with selectable thumbnails
- Tabbed interface for description, floor plan, and map
- Add and remove properties from favourites
- Persistent layout with sticky favourites panel
- Unit-tested filtering logic using Jest

---

## 🛠️ Tech Stack

- React
- React Router
- React Tabs
- rc-slider
- Jest (unit testing)
- CSS (custom styling)
